# Starter source files

Here you can open the code of every starter right on GitHub. For practice, download the archive from the lesson or the whole repository with **Code -> Download ZIP** and open the folder you need in PyCharm with the shared course environment.

Each folder has: `README.md` with the run order, `TASK.md` with hints, `local_llm.py` - the shared model-loading module, `get_models.py`, `requirements.txt`, the current modules, `demo_check.py` for a check without a model, `demo.py` for a run with the model and `tests/test_lesson.py`.
